┌──────────────────────────────────────────────────────────────────────────┐
│ 📊 MANIFEST CSV FORMAT                                                   │
└──────────────────────────────────────────────────────────────────────────┘

   Required columns:
   - pdb_path:         Full path to PDB file (use absolute paths!)
   - y:                Target value (e.g., binding affinity)
   - antibody_chains:  Chain IDs like "H,L" or "H:L" (quoted!)
   - antigen_chains:   Chain IDs like "A" or "A,B"

   ⚠️  IMPORTANT: Quote multi-chain values: "H,L" not H,L


┌──────────────────────────────────────────────────────────────────────────┐
│ 🔧 COMMON ISSUES                                                         │
└──────────────────────────────────────────────────────────────────────────┘

   "PDB file not found"
   → Use absolute paths in manifest
   → Or use --pdb-dir option

   "Chain X not found"
   → Check chain IDs: grep "^ATOM" file.pdb | awk '{print $5}' | sort -u
   → Update manifest with correct chains

   "No C-alpha atoms found"
   → Check for CA atoms: grep "CA" file.pdb | head
   → Ensure standard PDB format

   CSV parsing errors
   → Quote multi-chain values: "H,L" not H,L
